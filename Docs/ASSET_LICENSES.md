## 3D Models

All 3D models are built from **Unity primitive shapes** (Sphere, Cube, Cylinder, Capsule, Quad) assembled in code via `ProjectSetupBuilder.cs` and `CharacterAndStadiumUpgrader.cs`.

**No third-party 3D models are used.**

---

## Fonts

TextMeshPro uses its **bundled default fonts** (Liberation Sans / LiberationSans SDF). No custom fonts imported.

---

## Audio

All audio is **procedurally synthesized** at runtime via `AudioManager.cs` using mathematical waveforms (`Math.Sin`). No external audio files are used.

**No third-party audio assets are included.**

---

## Summary

This project uses **zero third-party assets** beyond Unity's own packages. All code, textures, models, and audio are original work by A&R Game Labs or generated procedurally at build/runtime.
